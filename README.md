# Gamerlay

Gaming overlay for myself!

## Props

### Clock

Showing current time at left bottom corner of screen.

### Dot

Showing dot at center of screen, can help to prevent motion sickness in first-person 3D games.

## Hotkey

### Shift + F9

Exit

### Shift + F10

Show/Hide All Props

### Shift + F11

Cycle Through Showing/Hiding Props
